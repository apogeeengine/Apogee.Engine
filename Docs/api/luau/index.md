# Luau API

Luau is the only scripting language, for games and for mods. This reference is written by `Apogee.Runtime --luau-docs` from the engine's registry (the classes the source generator described, the script libraries and the hand-written natives), the same
source as the type definitions for luau-lsp (`--luau-defs`, see [Scripting](../../manual/scripting/scripting.md)).

Open the [reference](reference.md): the globals a game sets, every class, every library, and the [enums](enums.md).
