# API reference

Two references, both generated from the code so they cannot drift from it:

- **[C# API](csharp/index.md)**: every public type of the engine's libraries, from the XML documentation comments (DocFX).
- **[Luau API](luau/index.md)**: what scripts and mods can use: classes, libraries, enums and the globals a game sets, from the same registry that gives luau-lsp its type definitions.

The raw native bindings (`Apogee.Native.*`) are not listed: they mirror the C headers of their libraries, which document them.
