# Default UI font

`Inter-Regular.ttf`, `Inter-Bold.ttf` and `Inter-Italic.ttf` are from Inter 4.1 (https://github.com/rsms/inter, release `Inter-4.1.zip`, sha256 9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e,
`extras/ttf/`), unchanged. License: the SIL Open Font License 1.1 (`Inter-LICENSE.txt`; "Copyright (c) 2016 The Inter Project Authors"), which allows bundling in games, closed source ones included, as long as the notice
travels with it (`Legal/THIRD_PARTY_NOTICES.md`). They are embedded in `Apogee.UI.dll` and registered as the family `Inter`, the default of `ui_base.rcss`.
